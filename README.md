# 快速启动

DeepSeek Harness（DSH）Web 界面的侧栏插件。左侧栏新增「快速启动」入口，主内容区打开一个快捷方式页：左边是启动项列表，右边是可分栏的终端区。可以一键打开文件夹、启动应用，或在右侧终端里运行命令。

## 功能

- 侧栏全局面板入口，排在「插件」「自动化任务」之前，折叠侧栏时只剩图标。
- 两类快捷方式：
  - 打开路径：文件夹用资源管理器打开，可执行文件（exe、lnk、bat 等）直接启动，其它文件用系统默认程序打开。
  - 运行命令：在右侧终端里执行，命令文本与工作目录可配置，可选「正常结束后自动关闭终端」。
- 左侧启动项列表是紧凑单行：类型图标、名称、一行目标摘要；悬停显示编辑、删除；点整行执行。
- 右侧终端区按分组排列，每个分组自带标签栏：
  - 拖动标签到分组边缘可以分栏（左右或上下），拖到整个终端区右侧或底部会新增一列或一行。
  - 标签可以在分组之间拖动，分组标签栏右侧的「+」在该分组新建空白终端。
  - 同时最多 9 个分组、12 个终端；分组超过 9 个时回退并提示。
  - 关闭分组里最后一个标签后分组消失，剩余分组重新分配空间。
- 终端对接主机上的真实 PowerShell 会话（xterm 渲染）：可输入、Ctrl+C、颜色、滚动回看、复制粘贴、随窗口改尺寸。
- 命令正常结束且勾选自动关闭时，标签自动消失；异常退出时保留标签并显示失败状态点与退出码提示。
- 切换面板或刷新页面后，终端继续在主机上运行，回到页面自动重连并重放最近输出；终端分组布局也会恢复。
- 快捷方式全局一份，保存在主机侧 JSON 文件里，所有会话共用。
- 界面文案中英文，配色跟随 DSH 主题。

## 安装

插件是一个本地包，路径就是本仓库。在 DSH 的插件管理器里用「本地目录安装」把绝对路径装进当前配置（本机已装进 `web` 配置）：

```
plugin_manager install_bundle target = D:\MyCode\dsh-quick-launch-bar
```

安装会把它作为链接依赖写入 profile 的 `package.json` 和 `packages` 列表，并挂载 `cordis.patch.yml` 里声明的插件行。安装后刷新页面，左侧栏出现「快速启动」。

## 使用

- 点侧栏「快速启动」打开页面。左侧点「新增快捷方式」添加条目。
- 「打开路径」可以手动填完整路径，也可以用「选择文件夹」调用系统的目录选择器，或用「选择程序」弹出系统的文件选择器直接挑 exe、快捷方式等文件。选中程序后名称为空会自动用文件名补上。
- 「运行命令」填写命令文本；工作目录留空时在用户主目录运行。命令由 PowerShell 7 执行，找不到时退回 Windows PowerShell 5。
- 点命令项会在右侧终端区当前分组里新建标签并执行；点打开路径项直接打开。
- 拖动终端标签可以分栏：拖到某个分组的边缘生成新分组，拖到另一个分组的标签栏则移动到那个分组。
- 点终端标签的关闭键终止该终端进程；分组里最后一个标签关闭后分组消失。
- 刷新页面或切到别的面板再回来，终端与分组布局会自动恢复。

## 数据

- 快捷方式数据文件：`%USERPROFILE%\.dsh\quick-launch\shortcuts.json`（`DSH_HOME` 有设置时以它为准），带 `version` 字段。
- 写入采用「临时文件 + rename」原子替换。
- 文件损坏时页面显示错误并禁止保存，不会覆盖原文件；修复或删除文件后重新打开页面即可。
- 终端分组布局存在浏览器 `localStorage` 的 `dsh-quick-launch-bar:workspace-layout:v1`，不写入主机；多个窗口各自保存，后写的覆盖先写的。
- 卸载插件不会删除快捷方式数据文件。

## 开发

```
package.json          插件清单（bundle patch、浏览器入口、locale、图标）
cordis.patch.yml      Loader patch：插入 quick-launch 行
index.js              主机 Cordis 插件（HTTP 接口、终端管理、事件流）
lib/host-core.js      主机纯逻辑（校验、存储、环形缓冲、启动参数），可单测
src/                  浏览器侧源码（页面、终端工作区、终端会话，JSX/JS）
client.js             浏览器产物，由 tools/build.mjs 生成，不要手改
tools/                构建与测试工具链
locale/               插件管理面板的中英文元数据
icon.svg              插件图标
docs/design.md        接口与行为设计
```

构建浏览器产物：

```
cd tools
npm install
node build.mjs
```

修改主机代码（`index.js`、`lib/`）后，需要在插件管理器里禁用再启用本插件或重启 DSH 才生效；只改浏览器代码时重新构建并刷新页面即可。

测试：

```
cd tools
npm install

# 主机纯逻辑单元测试
npm run test:unit

# Playwright 端到端测试（首次需要安装浏览器）
npx playwright install chromium
$env:QL_GUI_URL = 'http://127.0.0.1:3080'
$env:QL_DSH_TOKEN = '<启动 dsh web 时终端打印的 token>'
npm run test:e2e
```

没有启动 token 时，可以改用 `QL_DSH_COOKIE_FILE` 指向一个本机测试会话 Cookie 文件（`{name, value, expiresAt, authority}`）。两种方式二选一，凭据只从环境变量读取，不写入仓库。

Playwright 会驱动真实 GUI：登录、打开页面、增删改快捷方式、运行命令、检查自动关闭与重连、拖动标签分栏与布局恢复、9 个分组上限、刷新后持久化。测试开始前备份数据文件，结束后恢复；测试条目统一使用 `E2E-` 前缀。只跑一个 Playwright 实例，避免多个运行共用 `tools/e2e/artifacts` 互相清理。

## 边界与限制

- 仅支持 Windows。
- 快捷方式的命令按 PowerShell 语法执行；需要别的 shell 或临时命令时，在终端分组里点「+」开一个空白终端。
- 勾选「正常结束后自动关闭终端」的快捷方式在命令结束后标签会关闭；想留在终端里继续操作就不要勾选。
- 命令找不到时会以非零状态退出；勾选自动关闭时会保留终端便于查看。
- 打开路径等同于在资源管理器里双击：只保证系统接受了请求，系统随后报出的「没有关联程序」等错误不会回传。
- 「选择程序」的对话框由主机进程弹出，显示在 DSH 所在的电脑屏幕上；同时只能打开一个选择窗口。
- 终端进程随 DSH 进程结束；DSH 重启后不恢复终端。
- 同时最多 12 个终端、9 个分组；浏览器同源连接数有限，所以所有终端的输出共用一条事件流。
- 终端分组布局只存在当前浏览器，换浏览器或清空站点数据后回到单分组布局。
- 不注册 agent 工具，模型不能调用这些快捷方式。
